# Mother Editor

This repository is the working home for the Mother Editor project.

## Baseline
- Current baseline: Mother Editor Mobile V2.2.2
- Target: mobile-first digital product landing-page editor

## Development rules
1. Preserve the V2.2.2 baseline before making changes.
2. Make focused changes and avoid breaking existing editor functions.
3. Test desktop and mobile behavior after UI changes.
4. Keep deployment-related code isolated and documented.

## Project structure
- `index.html` — approved landing-page baseline currently stored in the repository.
- `CODEX.md` — instructions for safe AI-assisted development.

## Branching
Experimental/feature work should be done on a feature branch and reviewed before merging to `main`.

## Deployment
Cloudflare deployment is separate from this repository unless an explicit CI/CD workflow is configured and confirmed.
